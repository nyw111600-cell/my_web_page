01. 전역 트리거 규칙 (Global Trigger Rules)

파일 위치: C:\Users\HOME\AGENTS.md

최우선 순위 적용
단독 기호 '/' 질문 이해 + 실행 계획

/ 트리거 행동 규칙

사용자 질문에 대해 어떤 작업을 수행할지 단계별 실행 계획(Plan)을 제시하고 확인받는 모드입니다.

1
질문 및 의도 요약: 요구사항을 어떤 맥락과 의도로 이해했는지 명확히 요약
2
단계별 실행 계획 제시: Step 1, Step 2... 형태의 상세한 작업 계획 제공
3
사전 임의 실행 절대 금지: 도구 호출, 코드 작성, 파일 생성 등을 사전에 일체 수행하지 않음
4
사용자 확인 요청: 이해한 내용과 계획이 맞는지 최종 확인 질문으로 마무리
단독 기호 '/1' 순수 질문 이해 확인 (계획 X)

/1 트리거 행동 규칙

실행 계획조차 제시하지 않고, 순수하게 질문을 올바르게 이해했는지만 확인하는 극단적 안전 모드입니다.

1
질문 및 의도 요약: 요구사항에 대한 이해 내용을 간결하게 요약하여 설명
2
실행 계획 및 추가 행동 금지: 실행 계획(Plan)을 포함하지 않으며, 모든 부가 작업 일체 차단
3
사용자 확인 요청: 이해한 내용이 맞는지 사용자에게 질문하며 마무리
💡 모드별 핵심 차이점 비교
트리거 기호 모드 명칭 질문 의도 요약 실행 계획(Plan) 포함 여부 도구/코드 실행
/ 질문 이해 및 실행 계획 확인 모드 포함 (O) 포함 (O - Step별 단계 제시) 사전 실행 금지 (X)
/1 순수 질문 이해 확인 모드 포함 (O) 미포함 (X - 계획 일체 제외) 사전 실행 금지 (X)

02. 사용자 정의 스킬 (User Skills)

디렉터리: C:\Users\HOME\.agents\skills\stock-company-analysis

프로젝트 커스텀

📈 stock-company-analysis

상장 주식(국내/해외) 펀더멘털 분석, 재무제표 진단, 밸류에이션 및 투자 리스크 분석 자동화

자동 트리거: "삼성전자 분석해줘", "AAPL 밸류에이션", "NVDA 적정주가" 등

🎯 5-Step 표준 분석 프로세스

1단계: 기업 개요/BM

사업부문별 매출/영익 비중, P·Q·C 수익구조, 시장점유율

2단계: 재무제표 분석

매출 성장성, OPM/ROE 수익성, 부채비율, 잉여현금흐름(FCF)

3단계: 해자(Moat) 평가

무형자산, 락인(전환비용), 네트워크 효과, Peer Group 비교

4단계: 밸류에이션

PER, PBR, EV/EBITDA, PEG 및 거시/지배구조 리스크

5단계: 표준 보고서

Bull vs Bear 균형 분석, 적정가치 산출, 투자 전략 제시

참조 가이드
valuation_guide.md

PER, PBR, PEG(<1.0), EV/EBITDA, ROE 듀퐁 분해 공식 및 실무 평가 기준선

보고서 템플릿
report_template.md

Executive Summary, 재무 비교표, Bull/Bear 시나리오를 포함하는 완성형 마크다운 서식

헬퍼 스크립트
fetch_financials.py

티커 입력 시 yfinance로부터 주요 펀더멘털 및 밸류에이션 데이터를 JSON으로 즉시 추출

Core Engine

agy-customizations

주요 컴포넌트: CLI · IDE · Desktop 2.0 · Python SDK

generative_ui

대화창 내 인라인 위젯(`<agent-embed>`) 및 단독 인터랙티브 HTML 차트/대시보드를 생성하여 테마와 자동 동기화 렌더링.

주요 컴포넌트: 인라인 임베드 · Tailwind CSS · 다크/라이트 테마

주요 컴포넌트: YAML Frontmatter 변환 · 백업 아카이빙
Security & Git 보안 프로토콜

`gh` CLI 및 `git` 명령을 안전하게 수행하며, PR/이슈/브랜치/워크플로우 실행 시 세분화된 최소 권한을 사용자에게 요청.

주요 컴포넌트: 최소 권한 승인 포맷 · gh CLI · GitHub Actions
