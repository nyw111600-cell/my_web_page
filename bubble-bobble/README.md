# Bubble Bobble Mini (버블보블 미니)

HTML5 Canvas와 Vanilla JavaScript로 제작된 레트로 아케이드 게임 **버블보블(Bubble Bobble)** 미니 에디션입니다.

---

## 🎮 게임 특징
- **레트로 아케이드 스타일 픽셀 그래픽 & CRT 스캔라인 효과**
- **5개의 단계별 스테이지 (다중 스테이지 구현)**
- **버블 물리 시스템**:
  - 전방 방울 발사 및 부유
  - 몬스터 가두기 & 터뜨리기 (과일/보석 점수 획득)
  - 방울 위에 점프하여 튕겨 오르는 하이 점프
  - 바닥 구멍으로 떨어지면 천장으로 나오는 화면 래핑(Wrapping)
- **적 AI 및 공포의 Hurry Up! 시스템** (시간 지체 시 몬스터 폭주)
- **Web Audio API 8비트 칩튠 BGM 및 레트로 효과음**
- **모바일/태블릿 터치 컨트롤 지원**

---

## 🕹️ 조작 방법

| 동작 | 키보드 키 | 터치 버튼 |
|---|---|---|
| **좌 / 우 이동** | `◀` `▶` 또는 `A` / `D` | `◀`, `▶` 버튼 |
| **점프** | `▲` / `Space` / `W` / `Z` | `점프 (Z)` 버튼 |
| **발판 아래로 내리기** | `▼` + 점프 | `▼` + 점프 |
| **방울(버블) 발사** | `X` / `J` / `Enter` | `발사 (X)` 버튼 |
| **일시정지** | `P` | `일시정지` 버튼 |
| **사운드 ON/OFF** | `M` | `사운드 ON/OFF` 버튼 |
