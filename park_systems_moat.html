1. 독점적 원천 기술: True Non-Contact™ 모드 & 분리형 스캐너

Proprietary Physics Architecture

반데르발스 인력(Attractive Force) 영역 제어 원리

원자현미경은 탐침(Tip)과 시료 표면 원자 간의 상호작용력을 측정합니다. 기존 경쟁사들이 채택해온 태핑 모드(Tapping Mode)는 팁이 척력 영역(Repulsive Regime)까지 진입하여 시료를 주기적으로 두드리는 방식인 반면, 파크시스템스의 True Non-Contact™ 모드는 팁과 시료가 수 나노미터 거리를 유지하는 순수 인력 영역(Attractive Regime)에서 작동합니다.

Lennard-Jones 포텐셜 커브 영역 비교 무접촉·무손상 유지
경쟁사 (Tapping / Intermittent)

척력(Repulsive) 영역 침범. 1초에 수십만 번 시료를 강타하여 팁 첨단 마모(Tip Blunting)와 미세 패턴 손상 유발. 측정할수록 데이터 오차 확대.

파크시스템스 (True Non-Contact™)

인력(Attractive) 영역 유지. 공진 주파수 위상(Phase/Frequency Shift) 변화를 초고속 Z 피드백 제어로 추적하여 팁 마모 제로(Zero Wear) 구현.

기구학적 혁신: XY축과 Z축이 완전 분리된 독립형 스캐너 (Decoupled Scanner)

기존 단일 튜브 스캐너는 XY 스캐닝 시 발생하는 원호 운동으로 인해 Z축 뒤틀림(Background Bowing) 왜곡이 필연적이었습니다. 파크시스템스는 XY 평면 스캐너와 Z축 고속 스캐너를 물리적으로 완전히 분리하여 크로스토크(Crosstalk) 왜곡을 0%로 만들었으며, 소프트웨어적 후보정 없이도 원시 3D 데이터(Raw Data)의 절대 정밀도를 보장합니다.

4. 미세화 한계 돌파: 광학식 회절 한계와 AFM의 구조적 해자

Physics Paradigm Shift
광학식 계측 (Optical) 회절 한계 직면
d = λ / (2 · NA)

DUV(193nm) 광원의 물리적 한계로 인해 10nm 이하 미세 패턴의 직접 이미징이 불가능. 회절 산란광을 수학적 모델링으로 역추산하는 산란계측(OCD)은 실제 물리적 3D 프로파일 확인 불가능.

전자빔 계측 (CD-SEM) 2D 평면 & 시료 손상
수직(Z축) 단차 측정 불가

나노 수준의 2D 평면 해상도는 우수하나, 고에너지 전자빔 조사에 의한 감광액(PR) 수축(Shrinkage) 및 웨이퍼 전하 축적(Charging) 문제 발생. 수직 깊이 및 표면 거칠기(Roughness) 측정 한계.

원자현미경 (Park AFM) 대체 불가능
0.01nm 비파괴 3D 절대 계측

파장의 한계 없이 원자 간 인력으로 측정하여 0.1nm 수평 / 0.01nm 수직 분해능 달성. 전자빔 피폭 없는 완벽한 비파괴 검사로 미세 패턴 형상과 3D 거칠기를 절대 좌표로 구현.

왜 선단공정(GAA 2nm / 3D NAND / HBM4)으로 갈수록 AFM이 필수인가?

반도체가 수평 평면(Planar)에서 수직 3차원 적층 구조(GAA 나노시트 단차, 3D V-NAND 하베스트 홀, 하이브리드 본딩 구리 패드)로 진화하면서, 기존 2D CD-SEM과 광학 검사로는 수직 나노미터 단차와 표면 조도(Surface Roughness)를 감지할 수 없습니다. 파크시스템스의 AFM은 이 문제를 해결하는 전 세계 유일의 신뢰성 검증 장비입니다.

5. 미래 성장 드라이버: 차세대 반도체 패러다임을 선도하는 3대 축

Next-Gen Growth Engines
HBM4 / 어드밴스드 PKG

하이브리드 본딩 Cu 디싱 & 침식 계측

HBM4 및 3D SoC 적층 시 범프 없는 Cu-to-Cu 직접 접합(Direct Bonding)이 도입됩니다. 이때 접합면 CMP 연마 후 구리 패드가 과도하게 파이는 디싱(Dishing)이나 산화막 침식(Erosion)이 수 나노미터만 발생해도 보이드(Void) 불량으로 칩 전체가 폐기됩니다.
